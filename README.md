# ملک هانتر — ربات جست‌وجوی مخاطبین ملک

ربات تلگرام برای جست‌وجوی فازی در دفترچهٔ مخاطبین مشاوران املاک.

این مخزن فقط برای **اجرای ۲۴ ساعتهٔ ربات** روی GitHub Actions استفاده می‌شود؛
هر ۶ ساعت یک اجرای تازه شروع می‌شود و اجراهای هم‌زمان با concurrency مدیریت می‌شوند.

دادهٔ مخاطبین به‌صورت رمزنگاری‌شدهٔ AES-256 در `data/privdata.tar.enc` نگه داشته
می‌شود و کلید آن فقط در Secrets مخزن است — یعنی محتوای دفترچه حتی در مخزن عمومی
هم قابل خواندن نیست.

اجرای محلی:
```bash
pip install -r requirements.txt
DATA_KEY=... MELKBOT_TOKEN=... OWNER_ID=... python scripts/prepare_ci.py
python -m melkbot.bot
```
